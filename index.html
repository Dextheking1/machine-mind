A model plays a machine. Quest #19179.

Demo mode - canned session No key set
Demo mode: no key set, so the machine runs a small canned session locally. Add a key and a real Pollinations model plays the full machine.

Local commands: clear wipes the screen, reset reboots the machine to a fresh state. Everything else goes to the machine. Up arrow recalls the last command.

1. Your Pollen key

Bring your own Pollen. Paste a Pollinations secret key (sk_...) below. The key is stored only in this browser, in localStorage, and requests go only to gen.pollinations.ai. No key? The terminal still runs in demo mode with a clearly labelled canned session.

Get a key at enter.pollinations.ai. One command is one small chat call.
